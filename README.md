# Employee Management System

## 📌 Project Overview

The **Employee Management System** is a desktop-based application developed using **Python** and **MySQL**. It helps manage employee information efficiently through basic CRUD operations such as adding, updating, deleting, searching, and viewing employee records.

## 🚀 Features

* Add new employee records
* View employee details
* Update employee information
* Delete employee records
* Search employees
* Automatic Employee ID generation
* Input validation
* User-friendly interface
* MySQL database integration

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface
* **MySQL** – Database
* **MySQL Connector/Python** – Database connectivity
